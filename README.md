# AFRODONKE — Coach Phil's Dance Portfolio

A responsive, single-page profile for AFRODONKE (Coach Phil / Thee Feel), built with plain HTML, CSS, and JavaScript. It has no build step or package dependencies; open `index.html` in a browser to preview it.

## Customize

The first-person profile, contact details, school names, official media links, and class photos are based on information supplied for this portfolio. Confirm details and obtain any needed student/guardian permissions before publishing. The gallery currently includes the supplied JPG/JPEG photos; HEIC and video files are not included.

Web fonts load from Google Fonts and require an internet connection. System font fallbacks are included.
